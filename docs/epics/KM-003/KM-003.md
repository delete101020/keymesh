# KM-003 — App v2 chạy cục bộ

Dựng app v2 từ prototype `design/` trên lõi KM-001: module `store` (IndexedDB riêng cho từng vault, `meta.account`) và `ui` (3 cột desktop, stack mobile). Thiết lập tài khoản cục bộ với một vault mặc định, mở khoá bằng master password khi offline, khoá thủ công và tự khoá khi không thao tác; project/env; item 9 loại với field mẫu, gán nhiều env, fork, nhân bản, lịch sử kèm diff, hết hạn, sinh mật khẩu, field OTP (nhập secret/URI, quét QR), field từ file; lọc, tìm kiếm, copy tự xoá clipboard; import file v1. Chưa có server, PWA hay UI thùng rác.
