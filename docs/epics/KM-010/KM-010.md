# KM-010 — Backup, bản sao file và export Bitwarden

Tải backup `keymesh-backup` đã mã hoá (một hoặc mọi vault) và import lại backup v2 vào vault đang chọn hoặc vault mới; bản sao tự động chỉ ghi ra file trên Chromium desktop, báo khi cần cấp lại quyền; export Bitwarden JSON dạng tổ chức theo từng vault (mỗi `Project/env` là một collection, item dùng chung có nhiều `collectionIds`, field `otp` → `login.totp`), phải nhập lại mật khẩu trước khi export.
